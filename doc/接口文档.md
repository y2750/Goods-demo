# 接口文档

## app 端

**baseUrl** ：localhsot:8080

### 商品列表

/goods/list

参数：

无

返回：

```json
{
    list: [
        {
            mainImage: [String],
    		title: [String],
    		price: [Float],
    		goodsId: [Int]
        }
    ]
}
```

###  商品详情

/goods/info

参数：

goodsId:[Int]

返回：

```json
{
    goodsImages: [String[]],
    title: [String],
    price: [Float],
    description: [String],
    goodsId: [Int]
}
```

## console 端

**baseUrl** ：localhsot:8081

### 商品新增

/goods/create

参数：

goodsImages: [String],
title: [String],
price: [Float],
description: [String]

返回：

成功 or 失败

### 商品修改

/goods/update

参数：

goodsImages: [String],
title: [String],
price: [Float],
description: [String],
goodsId: [Int]

返回：

成功 or 失败

### 商品删除

/goods/delete

参数：

goodsId:[Int]

返回：

成功 or 失败

# 数据库设计

```mysq
CREATE TABLE `goods` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `images` varchar(2000) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '轮播图，$拼接',
  `title` varchar(50) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '商品名称',
  `price` decimal(10,2) NOT NULL COMMENT '价格',
  `description` varchar(2000) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '商品描述',
  `create_time` int unsigned NOT NULL,
  `update_time` int unsigned NOT NULL,
  `is_deleted` tinyint unsigned NOT NULL DEFAULT '0',
  PRIMARY KEY (`id`),
  KEY `idx_title` (`title`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='商品表';

```
