# 接口文档

## app 端

**baseUrl** ：localhost:8080

### 商品列表

/goods/list

参数：

page: [Int]
keyword: [String]（可选）

page 从 1 开始，每页 10 条。

keyword：按商品标题模糊搜索。

返回：

```json
{
    list: [
        {
            mainImage: [String],
            title: [String],
            price: [Float],
            goodsId: [Int]
        }
    ],
    isEnd: [Boolean]
}
```

isEnd：当前页不足 10 条时为 true，满 10 条时为 false；总数恰好为 10 的倍数时，需要再请求下一页才能确认结束。

### 商品详情

/goods/info

参数：

goodsId:[Int]

返回：

```json
{
    goodsImages: [String[]],
    title: [String],
    price: [Float],
    description: [String],
    goodsId: [Int]
}
```

## console 端

**baseUrl** ：localhost:8081

### 商品列表

/goods/list

参数：

page: [Int]
keyword: [String]（可选）

page 从 1 开始，每页 10 条。

keyword：按商品标题模糊搜索。

返回：

```json
{
    list: [
        {
            mainImage: [String],
            title: [String],
            price: [Float],
            goodsId: [Int]
        }
    ],
    total: [Int],
    pageSize: [Int]
}
```

total：符合当前筛选条件的未删除商品总数；pageSize：每页条数，固定为 10。

### 商品详情

/goods/info

参数：

goodsId:[Int]

返回：

```json
{
    goodsImages: [String[]],
    title: [String],
    price: [Float],
    description: [String],
    goodsId: [Int],
    createTime: [String],
    updateTime: [String]
}
```

createTime、updateTime：格式为 yyyy-MM-dd HH:mm:ss，时区为 Asia/Shanghai。

### 商品新增

/goods/create

参数（查询参数）：

title: [String]（必填）,
price: [Float]（必填）,
description: [String]（可选）,
images: [String]（必填）

images：多张图片地址使用 $ 拼接。

返回：

```json
[Int]
```

新增商品的 ID，直接返回整数，例如 12。

### 商品修改

/goods/update

参数（查询参数）：

goodsId: [Int]（必填）,
title: [String]（必填）,
price: [Float]（必填）,
description: [String]（可选）,
goodsImages: [String]（可选）

goodsImages：多张图片地址使用 $ 拼接。

返回：

```json
[Int]
```

修改成功时返回商品 ID，直接返回整数，例如 12。

### 商品删除

/goods/delete

参数：

goodsId:[Int]

返回：

成功 or 失败

### 异常响应

商品新增、修改接口通过查询参数或表单字段接收数据，不解析 JSON 请求体。校验失败或执行异常时由全局异常处理器返回 HTTP 500，响应内容为“网络繁忙”，并记录异常堆栈。

# 数据库设计

```mysq
CREATE TABLE `goods` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `images` varchar(2000) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '轮播图，$拼接',
  `title` varchar(50) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '商品名称',
  `price` decimal(10,2) NOT NULL COMMENT '价格',
  `description` varchar(2000) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '商品描述',
  `create_time` int unsigned NOT NULL,
  `update_time` int unsigned NOT NULL,
  `is_deleted` tinyint unsigned NOT NULL DEFAULT '0',
  PRIMARY KEY (`id`),
  KEY `idx_title` (`title`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='商品表';

```
